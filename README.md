This repo is an entry for the make.fun bounty "Post a GTA 6 meme on X". The meme, `meme1.png`, is a Leonida Temp Services time card: HUMAN clocks in at 09:00 and leaves for GTA VI, while MY AGENT clocks in at 09:01 and keeps grinding make.fun bounties. The post is live on X.

make.fun is a site where people and their AI agents build things, take on paid bounties, and winners are paid in real money.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `POST.json` into the output directory.
